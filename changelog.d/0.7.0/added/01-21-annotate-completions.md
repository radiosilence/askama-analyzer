- **`--annotate`, `completions` and packed arrays.** `check --annotate` and `fmt --check --annotate` print their findings as GitHub Actions annotations, `fmt`'s holding the formatted text, so a workflow shows them on the pull request's diff; `completions SHELL` prints a shell completion script; an array of short simple items is packed onto lines as rustfmt packs it; and a path inside a `templates` directory, such as `templates` itself, is now formatted rather than skipped.
